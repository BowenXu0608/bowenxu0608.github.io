# Continuous terrain streaming acceptance

Status: **PASS**. Separate non-Development `0.5.1-streaming` D3D11 diagnostic package; accepted Windows 0.4.0 remains preserved.

The original twenty v9 gallery recipes were replayed without screening. Four real capsule walks per seed cross a local-window boundary in clear and storm weather; six scripted cross-region relocations test disposal and rebuilding separately. Seed 777 additionally exercises both production LOD directions, an actual angular-wrap walk, a true surface hole and broken thin-ice retirement/reload. Historical v8/Mono512 receives its own extended run. The walks are short boundary fixtures, not a complete-world traversal or hour-long soak.

All twenty runs: 17,341 assertions. Historical v8: 1,078 assertions, world `EFAC05C15C192157`. Source fingerprint: `037457c6ce80e64039e03097b9675d909e84103cc52ed3180f06af937fb32d9c`.

Independent checks: [1,297 policy/interpolation/scheduling checks](streaming-check.txt) and [364 shared-rule checks](shared-rules-check.txt) pass. The [final build receipt](candidate-build.txt) records a successful non-Development build.

## Geometry and visuals

Six genuine before/after 1600x900 pairs use the same immutable adapter, frozen seed, cameras, hour and quality: near clear/storm, LOD refinement/coarsening midpoints and settled fine/coarse endpoints. All comparisons were inspected. Near frames are identical; settled endpoints differ by at most one channel unit. The intermediate terrain height and Global Snow replacement/depth passes now move together, removing the reproduced false blue gap. The historical baseline midpoint is its immediate target; the new midpoint is the interpolation at 0.5.

![Refinement midpoint comparison](lod-refine-mid-comparison.png)

All twenty actual 1600x900 [storm walking captures](Player/contact-sheet.png) were inspected for black output and missing materials. Near-ground texture and snow render normally, while storm fog obscures distant detail. These short camera fixtures do not establish every-view geometry coverage; the fixed pairs and physical assertions provide the separate geometry evidence. Exact inspected frame hashes are in [Player-inspection.json](Player-inspection.json).

Each walking frame checks physical ray support and ready collision. Feature locks preserve gap-bank cells, explicit walls/floors, pond banks and local collision during distant morphing. Extended tests verify absent authoritative hole support and no false top collision, stable angle-wrap walking, and weak plates staying broken after reload. Existing long explicit pit-wall triangles can still emit PhysX >500-unit warnings; exact warnings are retained in acceptance.json and Player logs. No runtime exception, NaN or invalid-bounds log is accepted.

Exact suffix vertex compaction preserves the leading sample grid and merges only bit-identical position/normal/tangent/color tuples, including signed zero. All faces and their order remain. The seven-case [ordered triangle-attribute audit](mesh-compaction-audit.json), including morph deltas, static geometry, angular wrap, gaps and a hole, matches SHA256 before/after. Some clipped meshes lose 46% of duplicate vertices. Six fixed-camera frames after static packing, lazy-normal retention and compaction are byte-identical to the earlier accepted after captures; recheck receipts are retained.

## Provenance and compatibility

The full candidate Assets/Packages/ProjectSettings snapshot was taken while the shared source was held unchanged after building. All 167 package files are hashed and reverified after serial validation. Later unrelated NPC source edits are allowed; production streaming inputs remain identical. Exact candidate probe/build sources are archived under [Adapters](Adapters/). The separate legacy package has its own full source/script/package seal and uses exactly the same production renderer, ice, policy and shader inputs. The baseline package is hashed separately and its renderer input hashes match the genuine baseline. Because unrelated NPC edits overlapped the earlier historical checkout snapshot, that full baseline checkout is not certified as the package source.

The first v8 fixture failed: v8 intentionally returns true from the v9-specific segment check, so the generic fixture selector could choose an original non-walkable cell. Enabling the current gameplay controller also attempted to write a v2 state through the v5-only save validator. This failed run is preserved under Logs/PolarStreaming/candidate-Player/legacy-seed-777-select-save-failure. The isolated legacy probe samples original traversal flags and slopes along its selected walk, excludes thin ice from the normal ground route, disables gameplay Update and suppresses gameplay saving. Actual capsule input, collision, renderer and streaming remain active. It does not convert or continue an old save. The successful legacy package and adapter hashes are recorded in [legacy-package.json](legacy-package.json) and [legacy-source.json](legacy-source.json); all twenty v9 runs retain their original sealed package.

The first separate legacy build succeeded but failed source binding when a concurrently edited acceptance-only script differed from its pre-build hash. That package is preserved as PolarStreaming-legacy-20261003-source-drift and was never accepted. The accepted compatibility build was recorded and rebuilt after the other task acknowledged the source freeze. This did not change production rendering inputs.

Five non-accepted diagnostic attempts are [recorded](failed-attempts.json) with preserved package/result archives. An idle fixture setup run was interrupted at 6.465GB; seed 12345 subsequently passed function/frame checks but failed memory at 5.252, 5.239, 5.159 and 5.150GB as successive changes were tested. Stage counters identify a stable managed heap and large native terrain buffers, motivating exact vertex compaction. The graphics counter returns zero in this non-Development Player and is unavailable, not proof of zero graphics memory. Final ordinary terrain uses the original 56-byte layout; only active morph displays use 80 bytes and retire when settled. Other changes reuse worker scratch lists, allocate clipping lists lazily, retain only coarse positions, recreate coarse normals on demand, release distant-ice CPU copies and clear large upload/retirement references. The final opt-in harness permits ordinary streaming during actual walking and initial warm-up, then gates automatic selection only during idle fixture setup. All twenty final recipes use the same revised package; no failed original seed was discarded or replaced. The earlier invalid movement-state-enum baseline assertion is also preserved; final support assertions use actual collider rays.

Terrain v9 and historical v8 keep their recipe identities and geometry. Gameplay save compatibility remains owned by its rule version: the current v5 source requires a fresh expedition and does not claim historical v2 continuation. Historical 0.4.0 v2/v3 acceptance remains attached to that archived production behavior. No full v5 NPC/gameplay release or exploration/resource calibration is certified here.

Known accepted build diagnostic: the vendor CTI/LOD Leaves 301 duplicate LOD_FADE_CROSSFADE warning/error reported by Unity; both builds succeed without a new compilation error. The Global Snow morph bridge is a maintained vendor integration.
